## HelmMGとは？

HelmMGは、実行時の処理管理を目的に設計されたドメイン固有言語（DSL）です。プログラムやファイル間の実行順序、並列実行、依存関係、条件、および同期を定義できます。

## 特長

- **実行時の処理管理**
- **順次実行**
- **並列実行**
- **条件付き実行**
- **依存関係の管理**
- **同期**
- **シンプルな構文**
- **軽量なインタープリター**
- **オープンソース**

## フォルダー構成

| フォルダー | 説明 |
|---------|-------------|
| `Languages` | 各言語の README ファイル |
| `include` | ヘッダーファイルとライブラリ |
| `ctrl` | 実行時制御の中核ロジック |
| `interpreter` | HelmMG 言語のインタープリター |
| `Docs` | ドキュメントと学習リソース |

## インストール

HelmMGをインストールするには、プロジェクトの GitHub Releases ページから最新リリースをダウンロードしてください。
