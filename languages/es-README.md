## ¿Qué es HelmMG?

HelmMG es un lenguaje de dominio específico (DSL) diseñado para gestionar la ejecución en tiempo de ejecución. Permite definir el orden de ejecución, la ejecución en paralelo, las dependencias, las condiciones y la sincronización entre programas y archivos.

## Características

- **Gestión de la ejecución en tiempo de ejecución**
- **Ejecución secuencial**
- **Ejecución en paralelo**
- **Ejecución condicional**
- **Gestión de dependencias**
- **Sincronización**
- **Sintaxis sencilla**
- **Intérprete ligero**
- **Código abierto**
