## 什么是 HelmMG？

HelmMG 是一种专为运行时执行管理而设计的领域特定语言（DSL）。它可以用于定义执行顺序、并行执行、依赖关系、条件，以及程序与文件之间的同步。

## 功能特点

- **运行时执行管理**
- **顺序执行**
- **并行执行**
- **条件执行**
- **依赖关系管理**
- **同步**
- **语法简单**
- **轻量级解释器**
- **开源**

## 文件夹结构

| 文件夹 | 说明 |
|---------|-------------|
| `Languages` | 不同语言的 README 文件 |
| `include` | 头文件和库 |
| `ctrl` | 核心运行时控制逻辑 |
| `interpreter` | HelmMG 语言解释器 |
| `Docs` | 文档和学习资源 |
