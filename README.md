## What Is HelmMG?

HelmMG is a domain-specific language (DSL) designed for runtime execution management. It allows users to define execution order, parallel execution, dependencies, conditions, and synchronization between programs and files.

## Features

- **Runtime Execution Management**
- **Sequential Execution**
- **Parallel Execution**
- **Conditional Execution**
- **Dependency Management**
- **Synchronization**
- **Simple Syntax**
- **Lightweight Interpreter**
- **Open Source**
